# AI 반려견 케어 메이트 PRD

## 1. 프로젝트 개요

### 1.1 프로젝트명

**AI 반려견 케어 메이트 (AI Dog Care Mate)**

### 1.2 한 줄 소개

혼자 있는 반려견의 행동과 주변 환경을 AI로 분석하고, 필요한 경우 놀이·음성·간식 등의 상호작용을 제공하는 **AI + Arduino 기반 반려견 케어 시스템**이다.

### 1.3 문제 정의

반려견은 보호자가 외출한 동안 혼자 있는 시간이 발생한다. 이때 보호자는 반려견이 현재 어떤 상태인지 직접 확인하기 어렵다.

특히 다음과 같은 문제가 발생할 수 있다.

* 장시간 혼자 있어 지루하거나 불안할 수 있음
* 평소와 다른 이상 행동을 보호자가 즉시 알아채기 어려움
* 실내 온도 등 환경 변화에 대응하기 어려움
* 단순 CCTV는 상황을 보여주지만 직접적인 상호작용은 부족함
* 기존 자동 급식기는 정해진 시간에 동작할 뿐 반려견의 현재 상태를 고려하지 못함

따라서 **반려견의 상태를 인식하고 상황에 맞게 능동적으로 반응하는 시스템**을 개발한다.

---

# 2. 목표

## 2.1 핵심 목표

1. 카메라와 센서를 통해 반려견의 상태 및 주변 환경을 수집한다.
2. AI를 활용하여 반려견의 행동을 분석한다.
3. 분석 결과에 따라 Arduino가 적절한 행동을 수행한다.
4. 보호자가 원격으로 반려견의 상태를 확인할 수 있도록 한다.
5. 반려견별 행동 패턴을 축적하여 개인화된 케어가 가능하도록 한다.

## 2.2 MVP 목표

첫 번째 버전에서는 다음 기능을 구현하는 것을 목표로 한다.

* 반려견 존재/위치 감지
* 반려견 행동 분석
* 온도/습도 측정
* 일정 시간 이상 활동이 없을 경우 감지
* 놀이 장치 자동 작동
* 보호자 목소리 재생
* 이상 상황 발생 시 알림
* 현재 상태 및 기록 확인

---

# 3. 핵심 사용자

### Primary User

반려견을 키우며 일정 시간 동안 집을 비우는 보호자

### Secondary User

* 반려견을 장시간 혼자 두어야 하는 사용자
* 반려견의 행동을 확인하고 싶은 사용자
* 반려견의 생활 패턴을 관리하고 싶은 사용자

---

# 4. 핵심 사용자 시나리오

### Scenario 1. 보호자가 외출

보호자가 집을 나간다.

→ 시스템이 반려견의 상태를 모니터링한다.

→ 반려견이 평소처럼 휴식한다면 별도의 동작을 하지 않는다.

---

### Scenario 2. 반려견이 장시간 활동하지 않음

AI가 일정 시간 동안 반려견의 움직임이 거의 없음을 감지한다.

→ 과도한 휴식인지 확인한다.

→ 놀이가 필요한 상태라고 판단되면 장난감 장치를 작동한다.

---

### Scenario 3. 반려견이 불안한 행동을 보임

AI가 반복적인 배회, 문 주변 체류 등의 행동을 감지한다.

→ 보호자에게 상태를 알린다.

→ 시스템은 설정된 경우 보호자의 음성을 재생한다.

---

### Scenario 4. 실내 온도가 상승

온도 센서가 높은 온도를 감지한다.

→ 시스템이 위험 수준인지 판단한다.

→ 보호자에게 알림을 보낸다.

---

### Scenario 5. 반려견이 놀이 장치에 접근

카메라가 반려견의 접근을 감지한다.

→ AI가 놀이 상황을 판단한다.

→ Arduino가 장난감을 작동시킨다.

---

# 5. 주요 기능

## 5.1 AI 행동 분석

카메라를 이용해 반려견의 행동을 분석한다.

### 초기 지원 행동

* 휴식
* 이동
* 배회
* 장난감 접근
* 문 주변 체류
* 장시간 움직임 없음

### 출력 예시

```text
현재 상태
휴식 중

활동량
낮음

특이 행동
없음
```

AI의 판단은 확정적인 감정 진단이 아니라 **행동 패턴에 기반한 상태 추정**으로 표시한다.

---

# 6. 환경 센서

Arduino에 센서를 연결하여 실내 환경을 측정한다.

### 수집 데이터

* 온도
* 습도
* 움직임
* 물그릇 상태
* 조도

### 예시

```text
온도: 24.5°C
습도: 52%
활동량: 낮음
물그릇: 정상
```

---

# 7. 자동 놀이 기능

AI가 놀이가 필요하다고 판단하면 Arduino가 장난감을 작동시킨다.

### 구성 예시

* 서보모터
* DC 모터
* 장난감 공
* 움직이는 깃털 장치

### 동작

```text
AI 분석
 ↓
놀이 필요 판단
 ↓
Arduino 명령
 ↓
모터 작동
 ↓
반려견과 상호작용
```

무작정 반복 작동하지 않도록 **하루 최대 작동 횟수와 작동 간격을 설정**한다.

---

# 8. 보호자 음성 재생

보호자가 미리 녹음한 음성을 재생한다.

예:

> "초코야, 잘 지내고 있어?"

AI가 설정된 조건을 충족했을 때 음성을 재생한다.

### 조건 예시

* 일정 시간 이상 혼자 있음
* 불안 행동 감지
* 보호자가 앱에서 직접 실행

---

# 9. 보호자 알림

다음과 같은 상황에서 보호자에게 알림을 전송한다.

### 일반 알림

* 반려견 활동량 감소
* 놀이 장치 작동
* 음성 재생

### 중요 알림

* 높은 실내 온도
* 장시간 이상 행동
* 반려견 움직임 이상
* 센서 이상

                 ┌──────────────┐

# 17. 성공 기준

MVP가 다음 조건을 만족하면 성공으로 판단한다.

1. 카메라에서 반려견을 정상적으로 인식한다.
2. 최소 3가지 이상의 행동을 분류할 수 있다.
3. AI 판단 결과에 따라 Arduino 장치가 자동으로 작동한다.
4. 온도/습도 데이터를 실시간으로 확인할 수 있다.
5. 보호자가 원격으로 놀이/음성 기능을 실행할 수 있다.
6. 이상 상황 발생 시 보호자에게 알림을 전달할 수 있다.
7. 하루 동안의 반려견 행동 기록을 확인할 수 있다.

# 18. 향후 확장

### AI 개인화

처음에는 일반적인 행동 분류를 사용하고, 사용 기간이 늘어나면서 **개별 반려견의 평소 행동 패턴**을 학습한다.

### 다중 반려견 인식

여러 마리의 반려견을 개별적으로 식별한다.

### 스마트 급식

AI가 개체를 식별하고 급식 기록을 관리한다.

### 건강 이상 패턴 탐지

활동량, 수면, 식사 등의 장기적인 변화를 분석하여 평소와 다른 패턴을 보호자에게 알려준다.

### 스마트홈 연동

조명, 에어컨, 로봇청소기 등과 연동하여 반려견이 혼자 있는 환경을 자동으로 관리한다.

---

# 19. 프로젝트 차별점

기존 CCTV는 **관찰**에 초점이 있고, 기존 자동 급식기는 **정해진 시간에 동작**하는 데 초점이 있다.

본 프로젝트는

**관찰 → AI 분석 → 상황 판단 → 실제 행동 → 데이터 기록**

의 사이클을 구축하는 것을 목표로 한다.

즉, 단순히 반려견을 "보는 시스템"이 아니라 **혼자 있는 반려견에게 상황에 맞는 상호작용을 제공하는 AI 케어 시스템**을 지향한다.
