# 2. 프로젝트 개요

## 2.1 프로젝트 한 줄 소개

> **혼자 있는 반려동물의 행동을 AI가 학습·판단하고, 무선 IoT 모듈로 급식·급수·환경까지 직접 케어하는 스마트 펫케어 서비스**

## 2.2 프로젝트 소개

PetCare AI Hub는 보호자가 외출한 동안 반려동물의 행동과 주변 환경을 실시간으로 관찰하고, **AI가 평소 행동 패턴과 현재 상태를 비교**하여 이상 징후를 판단한 뒤, **무선 임베디드 모듈을 통해 직접 케어(장난감 작동·음성 재생·급식·급수·온습도 제어)까지 수행**하는 서비스이다.

기존 펫캠이 "보여주기"에 머물고, 기존 자동급식기가 "배급"에만 머무는 것과 달리, 본 프로젝트는 **관찰 → 판단 → 행동 → 학습**이 하나의 순환 구조로 연결된 **능동형 AI 반려동물 케어 시스템**을 지향한다.

# 3. 기획 배경

* **1인 가구 및 맞벌이 가구 증가**: 반려동물이 장시간 혼자 남겨지는 가구가 늘면서, 실시간 행동·환경·식습관 모니터링 필요성이 커지고 있음.
* **질병의 조기 발견 중요성**: 음수량 급감(신장·방광 질환 신호), 식욕 부진(내과 질환 신호), 평소와 다른 배회·휴식 패턴은 건강 이상의 핵심 지표이나, 보호자가 상시 확인하기 어려움.
* **기존 펫캠의 한계**: 영상만 보여줄 뿐, 보호자가 계속 확인하고 직접 판단·대응해야 하는 구조. 단순 움직임 감지는 "평소와 다른가"라는 맥락 정보를 제공하지 못함.
* **기존 단일 급식기의 한계**: 배급 기능에만 치중되어 있어 반려동물이 밥그릇·물그릇 주변을 서성이는 행동 데이터를 수집하지 못함.
* **기존 유선 통합 시스템의 한계**: 케이블 노출로 인한 미관 저하 및 반려동물의 전선 씹기 사고 위험.
* **초기 구매 비용 부담**: 고성능 임베디드 모듈·정밀 센서를 일시불로 구매할 경우 보호자의 초기 비용 부담이 큼.

이에 따라 우리는 **AI가 보호자를 대신해 행동을 관찰·판단하고, 필요 시 물리적으로 직접 개입**하는 시스템을, **부담 없는 구독형 모델**로 제공하고자 한다.

# 4. 문제 정의

## Problem 01. 보호자가 계속 관찰할 수 없다
카메라가 있어도 하루 종일 영상을 볼 수는 없어 중요한 상황을 놓칠 수 있다.

## Problem 02. 단순 감지는 의미가 없다
"움직였다/서성였다"보다 중요한 것은 **"평소와 비교했을 때 이상한가?"**이다.

## Problem 03. 반려동물마다 패턴이 다르다
활동량, 수면 시간, 음수·식사 습관은 개체마다 달라 동일 기준 적용이 부적절하다.

## Problem 04. 기존 제품은 보호자가 최종 판단·대응해야 한다
이상 상황을 알림으로 받아도 실질적 대응(급식·급수·환경 조절·달래기)은 결국 보호자 몫이다.

## Problem 05. 배선과 초기 비용이 진입 장벽이 된다
유선 통합형 제품은 설치 제약과 안전사고 위험이 있고, 고사양 하드웨어 일시불 구매는 부담이 크다.

# 7. 서비스 및 핵심 기능

## 7.1 🐶 반려동물 행동 분석 (Computer Vision)
카메라 기반으로 다음 행동을 인식·분류한다.

* 💤 휴식 · 🚶 이동 · 🎾 놀이 · 🔄 배회
* 🚪 문 주변 체류 · 🐕 장시간 움직임 없음
* 🍖 식사 (밥그릇 접근/서성임) · 💧 물 섭취 (물그릇 접근/서성임)

> 감정을 직접 진단하지 않고, **카메라·초음파 센서로 관찰 가능한 행동 패턴**만을 분석한다.

## 7.2 🧠 개인화 AI (핵심 차별화 기능)
개체별 데이터를 지속 수집해 **개별 행동 프로필**을 생성한다.

| 항목 | 예시 (초코) |
| :--- | :--- |
| 평균 활동량 | 63% |
| 평균 놀이 횟수 | 3.4회 |
| 평균 수면 시간 | 8.2시간 |
| 오전/오후 패턴 | 오전 활동량 높음 / 오후 주로 휴식 |

→ "배회하고 있다"가 아니라 **"평소보다 배회 행동이 많다"**로 판단.

## 7.3 ⚠️ 이상 행동·이상 신호 감지
행동(배회 시간 급증 등)뿐 아니라 **음수량 급감·식욕 부진**과 같은 생활 지표 변화도 함께 비교해 이상을 판단한다.

```text
평소 배회 10분 → 오늘 배회 42분  →  평소 대비 급증  →  ⚠️ 이상 패턴 감지
평소 음수량 150g → 오늘 40g      →  평소 대비 급감  →  ⚠️ 건강 이상 신호
```

## 7.4 🤖 AI 자동 케어 (물리적 개입)

| 상황 | AI 행동 |
| :--- | :--- |
| 장시간 활동 없음 | 🎾 장난감 작동 |
| 보호자 대기 행동 증가 | 🔊 보호자 음성 재생 |
| 사료/물 잔량 부족 | 🍚 자동 급식 · 💧 자동 급수 |
| 설정 온도 초과 | ❄️ 에어컨/냉방기 릴레이 ON |
| 설정 습도 미달 | 💦 가습기 릴레이 ON |
| 이상 행동 지속 | 📱 보호자 알림 |

## 7.5 🔄 개입 효과 학습
장치 작동 후 행동 변화를 재관찰하여 **개체별로 효과적인 케어 방식을 학습**한다.

```text
배회 증가 → 🔊 음성 재생 → 배회 감소 → "음성 재생 효과 있음"
음성 재생 → 변화 없음 → 🎾 장난감 작동 → 활동량 증가 → "장난감이 더 효과적"
```

## 7.6 📱 보호자 대시보드 & AI 데일리 리포트
실시간 상태(온·습도, 활동량, 사료/물 잔량, 서성인 횟수)와 하루 요약 리포트를 제공해 **보호자가 영상을 직접 확인하지 않아도** 되게 한다.

# 9. 하드웨어 모듈 상세 사양

## 9.0 [Module 0] AI 행동 인식 카메라 유닛 *(신규 통합)*
* **메인 MCU:** ESP32-CAM (또는 ESP32 + 별도 카메라 모듈)
* **영상 센서:** OV2640 이상급 카메라 모듈
* **모션 감지:** PIR 모션 센서 (저전력 상시 감시용 1차 트리거)
* **선택 확장:** 마이크(소음/짖음 감지), 스피커(보호자 음성 재생)
* **역할:** 행동 인식(휴식/이동/놀이/배회 등)의 1차 데이터 소스, PIR로 절전 트리거링 후 카메라 활성화

## 9.1 [Module 1] 스마트 급식 & 음수 유닛
* **메인 MCU:** ESP32 Dev Board (Xtensa Dual-Core 240MHz, Wi-Fi 802.11 b/g/n + BLE, 520KB SRAM / 4MB Flash)
* **접근 감지:** HC-SR04 초음파 센서 ×2 (측정범위 2–400cm, ±3mm)
* **잔량 측정:** 1kg 로드셀 + HX711 24-bit ADC ×2세트
* **급식 구동:** MG996R 고토크 서보모터 (9.4–11kg·cm, 0–180°)
* **급수 구동:** 5V 소형 수중 펌프 + 1채널 릴레이 (양정 0.4–1.5m, 80–120L/H)
* **전원부:** 5V 3A SMPS

## 9.2 [Module 2] 무선 환경 모니터링 HUB
* **메인 MCU:** ESP32 (또는 ESP8266 WEMOS D1 Mini)
* **온·습도 센서:** DHT22(AM2302), 온도 측정범위 영하 40℃부터 80℃까지(오차 ±0.5℃) / 습도 측정범위 0%부터 100%RH까지(오차 ±2–5%), 2초 샘플링
* **전원부:** 5V 1A USB-C

## 9.3 [Module 3] 스마트 환경 제어 플러그
* **메인 MCU:** ESP32
* **제어부:** 2–4채널 Optocoupler 격리 릴레이 (AC250V/DC30V, 10A) — 에어컨·난방기·가습기 직접 스위칭
* **전원부:** AC-DC 5V 내장형

> **모듈 통합 설계 원칙:** 모든 모듈은 독립 Wi-Fi 접속이 가능해 유선 연결 없이 배치되며, 중앙 클라우드에서 통합 데이터로 관리된다. (배선 제로화 = 반려동물 전선 씹기 사고 예방)

# 12. 차별화 및 경쟁력

시장에는 Furbo, Petcube 등 AI 펫캠과 단순 자동급식기가 있으나, "AI 카메라"나 "자동 배급" 하나만으로는 경쟁력이 부족하다.

| 기존 제품 | PetCare AI Hub |
| :--- | :--- |
| 관찰 → 알림 → **보호자 판단·대응** | 관찰 → 개인화 분석 → 판단 → **AI 자동 개입(급식·급수·환경·놀이)** → 결과 학습 |

### 핵심 경쟁력
1. **Individual AI** — 반려동물마다 다른 행동/음수/식사 패턴을 개별 학습
2. **Active Care** — 판단에 그치지 않고 실제 급식·급수·환경·놀이 장치를 직접 작동
3. **Intervention Learning** — 어떤 케어 방식이 효과적인지 개체별로 학습
4. **Wireless Modular** — 배선 없는 독립 모듈로 설치 자유도 극대화, 고사양 센서로 데이터 신뢰성 확보
5. **AI Daily Report** — 보호자가 영상을 직접 모니터링하지 않아도 되는 요약 정보 제공

# 19. 결론

PetCare AI Hub는 단순한 CCTV, 단순한 자동 급식기가 아니다.

행동 데이터를 지속적으로 수집해 **AI가 개별 반려동물의 평소 패턴을 이해**하며, 필요한 순간에는 **놀이·음성·급식·급수·환경 제어로 직접 개입**하고, 그 결과를 다시 학습하는 **개인화 AI 반려동물 케어 서비스**를 목표로 한다. 여기에 **배선 없는 무선 모듈 하드웨어**와 **부담 없는 구독형 가격 정책**을 결합해, 기술적 완성도와 시장 진입 장벽 해소를 동시에 달성한다.

> ## **"우리는 반려동물을 감시하는 AI가 아니라, 혼자 있는 반려동물과 함께하며 직접 돌보는 AI를 만듭니다."**
