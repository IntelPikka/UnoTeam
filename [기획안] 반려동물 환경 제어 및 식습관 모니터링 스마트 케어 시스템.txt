# [기획안] 반려동물 환경 제어 및 식습관 모니터링 스마트 케어 시스템

> **문서 버전:** v1.0  
> **작성일:** 2026. 08. 12  
> **프로젝트명:** PetCare Hub (펫케어 허브)

---

## 1. 기획 배경 및 목적

### 1.1. 배경
* **1인 가구 및 맞벌이 가구 증가:** 집에 홀로 남겨지는 반려동물의 수가 늘어남에 따라, 주인이 외출 중일 때 환경 관리 및 식습관 모니터링에 대한 니즈 증가.
* **질병의 조기 발견 중요성:** 반려동물의 음수량 감소나 식사 거부는 질병(음수량 감소 시 유구/방광염, 식욕 부진 시 내과 질환 등)의 주요 초기 신호임.
* **기존 제품의 한계:** 단순 자동 급식기는 사료 배급 기능만 제공할 뿐, 실제 반려동물이 밥이나 물을 얼마나 자주 찾는지에 대한 행동 패턴 데이터 수집이 불가능함.

### 1.2. 목적
* **환경 최적화:** 방 안의 온·습도를 실시간으로 감지하고 외부 기기를 제어하여 쾌적한 상태 유지.
* **행동 패턴 데이터화:** 밥그릇/물그릇 접근 횟수 및 체류 시간을 수치화하여 반려동물의 건강 이상 징후 파악.
* **원격 맞춤 배급:** 스마트폰 앱을 통한 원격 사료 배급, 자동 급수 및 잔량 모니터링 구현.

## 3. 주요 기능 명세 (System Features)

### 3.1. 스마트 환경 제어 (Environment Care)
* **실시간 온·습도 모니터링:** 고정밀 센서를 통해 방 안 환경을 1초 단위로 측정.
* **자동 릴레이 제어:** 설정한 적정 온·습도 범위를 벗어날 경우 릴레이 모듈을 통해 에어컨, 난방기, 가습기 등 외부 기기 자동 제어.

### 3.2. 식습관 & 음수 행동 감지 (Behavior Tracking)
* **접근 카운팅 알고리즘:** 밥그릇 및 물그릇 주위 일정 거리(예: 15cm) 이내에 3초 이상 체류 시 **'접근 횟수 1회'**로 간주하여 수치화.
* **일일 패턴 기록:** 시간대별 밥그릇/물그릇 서성임 횟수 (`Feed_Check_Count`, `Water_Check_Count`) 저장 및 스마트폰 데이터 전송.

### 3.3. 스마트 급식 및 급수 (Smart Feeding & Watering)
* **원격 / 예약 배급:** 모터 제어를 통한 사료 개폐구 구동 (앱에서 즉시 배급 버튼 클릭 가능).
* **자동 급수:** 수위 및 잔량을 파악하여 소형 워터 펌프로 깨끗한 물 공급.
* **실시간 잔량 측정:** 밥그릇/물그릇 하단 로드셀 센서를 통해 남은 사료 및 물의 무게(g) 실시간 측정.

### 3.4. 모바일 앱 연동 및 UI (Mobile App Interface)
* **Wi-Fi 클라우드 통신:** ESP32 모듈 기반의 실시간 데이터 대시보드 구현 (Blynk / Firebase / MQTT).
* **앱 화면 구성 요소:**
  1. 현재 방 안 온도 / 습도 (℃ / %)
  2. 오늘 밥그릇 서성인 횟수 / 물그릇 서성인 횟수 (회)
  3. 현재 사료 잔량 / 물 잔량 (g)
  4. 원격 배급 버튼 [사료 1회 배급], [물 보충]

## 4. 시스템 아키텍처 및 하드웨어 구성

### 4.1. 하드웨어 구성도 (Hardware List)

| 구분 | 주요 부품 | 역할 및 스펙 |
| :--- | :--- | :--- |
| **Main MCU** | **ESP32 Dev Board** | Wi-Fi/BLE 통신, 센서 데이터 처리 및 모터 제어 총괄 |
| **환경 감지** | DHT22 / SHT30 | 방 안 온도 및 습도 실시간 측정 센서 |
| **행동 감지** | HC-SR04 / VL53L0X | 초음파/ToF 거리를 측정하여 밥/물그릇 주변 접근 감지 |
| **무게 측정** | HX711 + 로드셀 (1kg) | 사료 및 물의 잔량(g) 측정 |
| **급식 구동** | MG996R 서보 모터 | 사료 디스펜서 개폐 구동 |
| **급수 구동** | 5V 워터 펌프 + 릴레이 | 수조의 물을 물그릇으로 이송 |
| **외부 제어** | 2채널/4채널 릴레이 | 냉·난방기, 가습기 등 외부 전원 제어 |
| **전원부** | 5V 3A SMPS 어댑터 | 모터 및 펌프의 안정적인 동작 전원 공급 |

### 4.2. 데이터 흐름도 (Data Flow)

```text
[센서 레이어]
 ├─ 온습도 센서 (DHT22)
 ├─ 거리 감지 센서 (초음파/ToF)
 └─ 무게 센서 (로드셀 HX711)
        │
        ▼
[제어 레이어 (ESP32 MCU)]
 ├─ 온습도 비교 ──> 외부 기기 릴레이 제어
 ├─ 접근 체류 판단 ──> 밥/물 서성임 카운트(+1) 계산
 └─ 무게 계산 ──> 잔량 데이터화
        │
        ▼ (Wi-Fi 통신)
[클라우드 / 서버] (Firebase or Blynk Server)
        │
        ▼
[모바일 앱 (사용자 UI)]
 ├─ 온습도 / 접근 횟수 / 잔량 수치 모니터링
 └─ [원격 배급 버튼 클릭] ──> ESP32 모터 구동 명령 전달
